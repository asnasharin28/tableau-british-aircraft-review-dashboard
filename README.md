# ✈️ British Airways Aircraft Review Dashboard — Tableau Project

## 📌 Project Overview
This project presents an interactive Tableau dashboard built to analyze British Airways customer review data across multiple dimensions.  
The dashboard highlights overall rating trends, aircraft performance, geographic insights, and detailed review metrics such as entertainment, food, cabin staff, seat comfort, ground service, and value for money.

Users can explore different aspects of the review data through dynamic metric selection and multiple filtering options, enabling a complete understanding of customer experience across aircraft models and regions.

---

## 🧩 What I Did in This Project

### **Dashboard Design**
I designed a single-page review analytics dashboard combining KPIs, trend analysis, aircraft comparisons, and geographic visuals.  
The main KPIs include:
- **Average Overall Rating**
- **Cabin Staff Service**
- **Entertainment**
- **Food & Beverages**
- **Ground Service**
- **Seat Comfort**
- **Value for Money**

These KPIs help summarize the overall customer experience at a glance.

### **Trend Analysis**
I built a **monthly trend line chart** showing how the overall rating has changed over time (2016–2024).  
This helps identify patterns, seasonal variations, and periods of high or low passenger satisfaction.

### **Geographic Insights**
A **world map visualization** shows the average rating by country, helping understand how ratings differ across regions based on traveler origin.

### **Aircraft Performance Comparison**
I created a combined horizontal bar chart showing:
- **Average overall rating by aircraft type**
- **Number of reviews per aircraft**

This helps quickly identify the best-performing aircraft and those receiving the most customer feedback.

### **Dynamic Metrics & Interactivity**
To improve user exploration, I added:
- A **metric selector** (Overall Rating, Entertainment, Food, Ground Service, Seat Comfort, Cabin Staff, Value)  
- Filters for:
  - Month of Date  
  - Traveller Type  
  - Seat Type  
  - Aircraft Group  
  - Continent  

These interactive elements allow users to analyze reviews using multiple perspectives.
